方法论

Agent = Model + Harness

Skill Card 六维框架

Intent / Trigger / Golden Examples / Boundary / Quality Bar / Integration Contract，用结构化方式定义 Agent 行为标准

Eval 体系

Golden Examples + 三层 Quality Bar（准确性 / 完整性 / 效率），用可度量的标准定义「什么是好」

Harness 设计

Guides（前馈控制）定义行为边界，Sensors（反馈控制）持续检测质量，把问题前置到设计阶段

Token 经济学

将 Token 成本作为产品设计的前置约束，能读 Trace 定位浪费环节，推动消耗从不可控走向可预算

概率性设计

为 AI 可能出错的场景设计降级策略、置信度表达、Human-in-the-loop 机制

产品判断

判断哪些场景该用 Agent 自动化、哪些必须留人工兜底，把有限资源砸在真正痛的地方
